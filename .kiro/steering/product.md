# Product Overview

This is a Web3 developer learning repository (web3-dev-notes) structured as a progressive curriculum. It covers blockchain fundamentals, smart contract development, and modern frontend frameworks for building decentralized applications (DApps).

## Learning Phases

- L0: Foundational blockchain concepts, Ethereum basics, wallet usage, and introductory Solidity exercises
- L1: Advanced assignments (in progress)
- Part1 (业务了解): Business domain understanding for Web3
- Part2 (概念扫盲): Core blockchain and smart contract concepts
- Part3-1-Solidity: Solidity language deep-dive with Hardhat projects
- Part3-2-Next: Next.js full-stack framework for Web3 frontends
- Part3-3-React: React fundamentals (SPA development)

## Key Projects

- NftAuction: An NFT auction smart contract with upgradeable proxy patterns (Transparent Proxy and UUPS)
- ERC20MinerReward: A basic ERC20 token contract
- Counter: A simple Hardhat 3 demo contract with tests
- next-demo: A Next.js app demonstrating App Router, RSC, CSR, layouts, and routing
- react-demo: A Create React App project for learning React basics

## Language

Documentation and assignment files are primarily written in Chinese (中文). Code comments may also be in Chinese.
